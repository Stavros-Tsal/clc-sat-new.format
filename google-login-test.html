Test: Google Sign-In (Firebase)

Πριν τρέξεις αυτό το αρχείο, χρειάζεσαι:
  1. Ένα δωρεάν Firebase project στο console.firebase.google.com
  2. Authentication → Sign-in method → ενεργοποίησε "Google"
  3. Έχεις ήδη το firebaseConfig σου από το project sat-greek-quiz-stavros — αντικατέστησε το placeholder object παρακάτω με τις πραγματικές τιμές
  4. Το localhost είναι ήδη αυτόματα authorized domain — δεν χρειάζεται να κάνεις τίποτα άλλο
  5. Άνοιξε αυτό το αρχείο μέσω τοπικού server (π.χ. python3 -m http.server 8000 στο φάκελο, μετά localhost:8000/real-google-login-local-test.html) — όχι με διπλό κλικ / file://, γιατί το Google Sign-In popup δεν δουλεύει από file://
Δεν έχεις συνδεθεί ακόμα.
